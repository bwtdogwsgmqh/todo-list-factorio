## Overview

Todo List adds a persistent in-game task management panel to Factorio where players can create, check off, and organize personal notes and build objectives. Notes persist across sessions in the save file and support markdown-style formatting for lists, priorities, and section headers, making large factory planning sessions more organized.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Todo List** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Persistent Notes** | Todo items saved in the Factorio save file across all game sessions |
| **Markdown Format** | Support for bold, bullets, and headers inside note items |
| **Checklist Mode** | Check off completed tasks to track progress on large build projects |
| **Session Planning** | Create shopping lists and build sequences for complex factory stages |
